# Login Interactif

Un mini projet frontend réalisé avec HTML, CSS et JavaScript.

Ce projet contient :

- un formulaire de connexion
- un formulaire de création de compte
- une interaction avec une lampe (mode sombre / clair)
- une validation simple des formulaires

---

## Aperçu

Quand l'utilisateur clique sur la lampe :

- le fond devient sombre
- le formulaire de connexion apparaît
- l'image change

L'utilisateur peut aussi ouvrir un formulaire de création de compte.

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla JS)

##  Fonctionnalités

### Login

- Vérification des champs vides
- Message d'erreur affiché en rouge

### Création de compte

- Affichage dynamique du formulaire
- Vérification des champs obligatoires

### Interaction lampe

- Changement d'image
- Activation du mode sombre
- Affichage/masquage des formulaires

---

## Comment lancer le projet

1. Télécharger le projet
2. Ouvrir le dossier
3. Double-cliquer sur `premier.html`

Ou utiliser VS Code avec **Live Server**.
